# shortsmith Privacy Policy

_Last updated: October 15, 2026_

shortsmith ("the tool") is a private, single-user tool built and operated by Jai Rajpal ("the operator"). It is used only to publish the operator's own original videos to the operator's own YouTube channel(s) and to read analytics for those videos. It is not offered to the public and has no other users.

## Use of YouTube API Services

shortsmith uses YouTube API Services. Use of the tool is subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms). YouTube API data is also subject to the [Google Privacy Policy](https://policies.google.com/privacy).

## What data the tool accesses

When the operator authorizes the tool with their own Google account, it may access:

- **Channel and video information** for the operator's own channel(s), such as channel ID, video IDs, titles, and publish status, so it can upload and manage the operator's videos.
- **Analytics for the operator's own videos**, such as views, watch time, and audience retention, so the operator can decide which topics to make next.
- **OAuth tokens** that Google issues so the tool can act on the operator's own account.

The tool does not access data belonging to any other YouTube user or Google account.

## How the data is used

The data is used only to upload the operator's videos and to analyze their performance for the operator's own content decisions. It is not used for advertising, profiling, or any other purpose.

## How the data is stored

- OAuth tokens and fetched data are stored privately on the operator's own computer and cloud storage that only the operator can access.
- Analytics data is stored only for as long as it is useful for planning content and is refreshed regularly from the YouTube API. Stored YouTube API data is refreshed or deleted in line with the YouTube API Services Developer Policies.

## Sharing

The tool does not sell, rent, share, or disclose any YouTube API data or Google user data to any third party.

## Cookies

The tool is a command-line program and does not use cookies or any device-tracking technology.

## Revoking access and deleting data

The operator can revoke the tool's access to their Google account at any time from the [Google security settings page](https://security.google.com/settings/security/permissions). After access is revoked, the tool deletes its stored tokens and any stored YouTube API data within 7 days.

## Changes

This policy may be updated as the tool changes. The "last updated" date above shows when it was last revised.
